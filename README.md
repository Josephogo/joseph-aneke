# FacultyHack@Gateways 2026 Curriculum Project

## Project Overview
This project redesigns **CSC 291: Introduction to Python Programming** at Hampton University to introduce students to scalable computing, High-Performance Computing (HPC), responsible Generative AI (GenAI) use, and reproducible computational workflows. The course serves students who already have foundational programming knowledge and builds Python skills through control structures, functions, collections, object-oriented programming, data analysis, and introductory machine learning. Through FacultyHack@Gateways 2026, the course is being extended beyond small, locally executed programming exercises toward authentic, data-intensive experiences using shared cyberinfrastructure. The redesigned course emphasizes one meaningful student workflow: prepare a real-world dataset, build a Python solution, critically evaluate GenAI-assisted debugging suggestions, run the workflow locally and on Jetstream2, compare execution behavior, and publish a reproducible GitHub project.

## Science Gateway Resources & Technology Notes

### Tools Used

**Jetstream2**  
- **Description:** A cloud-based research computing environment that provides access to advanced computing resources for research and education.
- **Course Use:** Primary student cyberinfrastructure environment for executing selected Python data-analysis and machine-learning workflows beyond the local desktop or Google Colab. Students will compare selected local and Jetstream2 executions and document when additional computing resources are beneficial.

**Cornell Virtual Workshop**  
- **Description:** An online instructional resource covering HPC, parallel computing, and research computing concepts.
- **Course Use:** Supporting instructional resource used to scaffold faculty and student understanding of HPC concepts and terminology.

**HPC Carpentry**  
- **Description:** Teaching materials and practices for introducing researchers and students to high-performance and research computing workflows.
- **Course Use:** Supporting curriculum resource for developing accessible activities on scalability, computational efficiency, reproducibility, and research computing.

**Generative AI Tools**  
- **Description:** AI-assisted programming tools that can suggest, explain, and debug Python code.
- **Course Use:** Students use GenAI in a structured debugging workflow: write code, review an AI suggestion, then **accept, modify, or reject** the suggestion with written justification based on correctness, efficiency, and appropriateness.

### Implementation Notes
- **Session 1:** Reviewed the original CSC 291 syllabus and identified opportunities to connect existing Python topics with computational efficiency, scalability, larger datasets, and research cyberinfrastructure.
- **Session 2:** Narrowed the student computing experience to one primary environment, **Jetstream2**, while retaining Cornell Virtual Workshop and HPC Carpentry as supporting instructional resources.
- **Session 3:** Redesigned learning outcomes to be measurable, including processing a large dataset, comparing local and Jetstream2 execution, critically evaluating AI-generated code, and documenting a reproducible workflow.
- **Session 4:** Redesigned the final project as a six-stage workflow: **Prepare Data → Build Python → Evaluate GenAI → Run on Jetstream2 → Compare Execution → Publish GitHub**.
- **Session 5:** Incorporated mentor feedback into the poster, project goals, student impact statements, and before-and-after curriculum narrative.

## Redesigned Student Workflow

1. **Prepare Data**  
   Select, inspect, clean, and document an authentic real-world dataset.

2. **Build Python**  
   Develop a Python workflow for data analysis, visualization, or an introductory machine-learning task.

3. **Evaluate GenAI**  
   Use GenAI to support debugging, then accept, modify, or reject suggestions with justification.

4. **Run on Jetstream2**  
   Execute the selected workflow using shared cyberinfrastructure.

5. **Compare Execution**  
   Compare local and Jetstream2 execution behavior and identify when additional computing resources are useful.

6. **Publish GitHub**  
   Publish a reproducible project containing code, data notes, results, dependencies, execution observations, and an AI-use reflection.

### Assessable New Outcomes
Students will be able to:
- process and analyze a large real-world dataset;
- execute and compare a Python workflow in local and Jetstream2 environments;
- critically evaluate AI-generated Python code for correctness and efficiency; and
- document and publish a reproducible computational workflow.
